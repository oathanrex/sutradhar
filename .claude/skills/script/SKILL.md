# script

A script that the edit cannot cut is a failed script. Write for the frame, not the page.

## Steps
1. **Read first**: `plan/brief.md`, `brand/about_me/voice.md`, `brand/rules.md`, `plan/promise.md`.
2. **Hook in the first 8-12 words, on screen and in the first 3 seconds.** Use the pack's `hook_patterns` as
   starting points, never as filler. Test: does sentence one create a question the viewer cannot leave unanswered?
3. **Write to the beat table.** One beat per row of `plan/brief.md`, each with a target duration. A beat that runs
   2x its target is where viewers leave - mark it and cut it before the edit does.
4. **One idea per sentence. One sentence per visual change.** If a sentence cannot be shown, it is written wrong.
5. **Put the retention beat where the pack says** - a turn, a number, a mistake, a contradiction. Every 20-30s in
   long form, every 5-8s in shorts.
6. **Numbers on screen are spoken numbers.** Never write "a lot of money" where the frame needs `₹1,20,000`.
7. **End with one action**, not three, and it must be possible today.
8. **Verify mechanically** before showing anything:
   - word count / spoken duration at the locale's words-per-minute (`hi` is slower than `en` - do not reuse an
     English timing budget)
   - longest sentence, weakest opener, AI-sounding phrases, beat drift vs the brief
   - `hinglish`: every technical word stays English, nothing is translated that the creator did not translate

## Done when
- [ ] hook is <= 12 words and names the payoff or the contradiction
- [ ] every beat has a duration within 30% of its target
- [ ] no sentence exceeds the locale's comfortable breath length
- [ ] the script filename is `videos/<name>/script.md` and the creator approved it line by line
- [ ] `voice.md` phrases appear at least twice; zero phrases from the AI-sounding list
