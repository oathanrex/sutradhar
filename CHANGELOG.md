# Changelog

## 1.2.0 — 2026-11-26

Reach: five Indian locales instead of two, four formats instead of two, and an install that does not start with
`git clone` for people who already use Claude Code.

**Added**
- **Locales `ta` (Tamil), `bn` (Bengali), `mr` (Marathi).** Each one owns the whisper model, caption ceiling,
  line height, caps policy, letter spacing and speed budget. Tamil gets 24 chars and line height 1.10 because it is
  agglutinative and its ascenders/descenders clip; Bengali gets 26 and 1.14 for conjuncts; Marathi reuses the
  Devanagari stack but tightens to 30. The matrix is now **240 combinations** (10 × 6 × 4).
- **`fonts.needs_script`** replaces the Devanagari special case. `resolve()` now warns about a Latin-only brand font
  for *any* script locale, and forces caption case to `NATIVE` for all of them.
- **Formats `vertical-4x5` and `square-1x1`** with their own safe zones and pace multipliers (×0.8 and ×0.85).
  `comedy` at 45 cuts/min becomes 52.9 in square and 64.3 in portrait without touching the pack.
- **`docs/LOCALES.md`** — why a language is a config, the full comparison table, per-OS font install, and how to add
  a locale in 15 minutes.
- **`docs/QUICKSTART-hi.md`** — the whole quickstart in Hindi, including what actually breaks in Hindi/Hinglish.
- **`.claude-plugin/plugin.json` + `marketplace.json`** so `sutra` installs as a Claude Code plugin marketplace,
  not only as a clone. `pyproject.toml` already exposes the `sutra` console script.
- `sutra doctor` reads the locale files and reports which script has no font installed, instead of assuming
  Devanagari is the only case.

**Tests**: 57 (was 55). The locale loop is discovered from `locales/*.json`, and every script-bearing locale is
asserted to disable caps, demand a font fallback, and use `large-v3`.

## 1.1.0 — 2026-11-26

The version that closes the hole from the v1.0 self-audit.

**Added**
- `sutra build` — `timeline.json` -> a self-contained shot-sheet player (`index.html`, scrub it in any browser,
  no engine needed) + a HyperFrames composition + a **receipt** with content hashes of the timeline, the assets
  and the resolved config. `check_html` proves structure: one timed element per shot, ascending starts, escaping.
- **The words gate is real.** Re-transcribes the render, diffs it against the voice's own word list, reports every
  lost word with a timestamp. The transcriber is injectable, so the logic is tested without a 3 GB model.
- **Flash gate** (photosensitivity, <= 3 luminance flashes/sec) built on a pure function over sampled frames.
- **Evidence enforcement.** Every pack must declare `evidence`; `sutra evidence add` computes `outlier_x` from
  views and the channel median, and refuses duplicates. Validation rejects a pack that claims `measured: true`
  with no rows, or an `outlier_x` that does not match the division.
- **Statistics in the loop**, replacing the "2 appearances" hunch: min 3 uses, bootstrapped 95% interval of the
  mean, MAD, and a 0.5%/5s materiality threshold. "Not enough data" is now the common, honest answer.
- **`sutra analytics`** — retention intake with no CSV export: OAuth device flow and the YouTube Analytics v2
  `audienceRetention` report, stdlib only, with injectable transport so it is testable offline.
- **`docs/demo.mp4`** — a real 30-second render of the demo timeline, generated by `scripts/make_demo.py`
  (Pillow + a static ffmpeg), so a stranger can watch the pacing before installing anything.
- **ffmpeg discovery** now falls back to the static binary inside the `imageio-ffmpeg` wheel; the audio gate
  works without a system ffmpeg and still prints the honest SKIP when neither exists.
- **pyproject.toml** with a `sutra` console script (`pipx install .`).
- CI now runs on **ubuntu, macos and windows x Python 3.10/3.12**, plus a job that renders the demo and asserts
  the render-dependent gates actually report PASS.
- 55 tests (was 21), including the CLI surface in subprocesses.

**Fixed during the audit**
- manifest paths used the OS separator, so a manifest written on Windows only matched a timeline by accident
- the legal gate printed the same offender many times
- `words`, `audio` and `flash` gates could not be distinguished from a PASS in the summary - SKIP is now explicit

**Still honest about**
- 0/10 packs are measured. The machinery to measure them exists; the 30 videos have to be watched by a human.
- `hyperframes.html` follows HyperFrames' documented composition shape, which is version-sensitive:
  `npx hyperframes check` before every render, and pin the version.


## 1.0.0 — 2026-11-26

First release. Merges the research and edit sides into one repo, one `brand/`, one install.

**Added**
- `sutra` CLI, standard library only: `doctor, resolve, init, pack, check, spec, gate, loop, library, stats`
- 10 category packs (tutorial, tool-review, faceless-explainer, finance, education, talking-head, story, vlog,
  comedy, gaming) — 60 pack x locale x format combinations, validated in CI
- 3 locales (en, hi, hinglish) that own the whisper model, caption width, caps policy and line height
- 2 formats (long-16x9, portrait-9x16) with post-merge pacing multipliers
- 5 publish gates: hook, pace, mobile, audio (LUFS + true peak), legal (licences)
- `sutra loop`: retention curve → shot kind → rule proposals, with a two-appearance minimum
- provenance on every resolved value (`sutra resolve` shows why each number is what it is)
- hand-written validators, so `git clone` is the entire install
- 21 tests, GitHub Actions on Python 3.10 and 3.12

**Fixed vs the repos it replaces**
- install line pointed at a repo name that does not exist
- `cp -r .claude/skills .agents/skills` failed on a fresh clone (`.agents/` missing) → `make sync`
- `final_check` used an English-only whisper model regardless of language → locale owns the model
- two repos, two `brand/` folders and two duplicated `about-me` skills → merged into one
- no tests, no CI, no releases → all three
